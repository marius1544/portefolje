Admin Dashboard

Administrasjonssystem for bookingplatformen Jobbguru

Om prosjektet

Admin Dashboard er administrasjonsdelen av bookingplattformen Jobbguru. Systemet lar administratorer holde oversikt over og styre alle bookinger, tilgjengelige tider og brukere på ett sted.

Funksjonalitet

  • Oversikt over kommende og tidligere bookinger
  • Kalenderstyring med tilgjengelige og blokkerte tider
  • Brukeradministrasjon med roller og tilganger
  • CRUD-funksjonalitet mot REST API
  • Sikker autentisering med JWT

Teknologier

REST API JWT CRUD MySQL Responsivt design
